Set up the board

Any board that can make an HTTP request works. Post a reading to

{{$d.Endpoint}}

with the header Authorization: Bearer {{$tok}} and a body like {"temperature": 21.4, "humidity": 18}. Either value can be left out. Once a minute is plenty.

ESPHome — add to the device's YAML; temp and hum are your sensors' ids 
http_request:
  verify_ssl: false

interval:
  - interval: 60s
    then:
      - http_request.post:
          url: {{$d.Endpoint}}
          request_headers:
            Authorization: "Bearer {{$tok}}"
            Content-Type: application/json
          json:
            temperature: !lambda return id(temp).state;
            humidity: !lambda return id(hum).state;
Arduino (ESP32) 
#include <WiFi.h>
#include <HTTPClient.h>

void sendReading(float t, float h) {
  HTTPClient http;
  http.begin("{{$d.Endpoint}}");
  http.addHeader("Authorization", "Bearer {{$tok}}");
  http.addHeader("Content-Type", "application/json");
  http.POST(String("{\"temperature\":") + t + ",\"humidity\":" + h + "}");
  http.end();
}
Shell, to test it 
curl -X POST {{$d.Endpoint}} \
  -H "Authorization: Bearer {{$tok}}" \
  -d '{"temperature": 21.4, "humidity": 18}'
